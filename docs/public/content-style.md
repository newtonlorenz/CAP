# User-facing text

Use [ASD-STE100 Issue 9](https://www.asd-ste100.org/) as the reference for
in-app text and public documentation. Keep product and regulatory terms when
they have a defined technical meaning. Use one term for each item.

- Give one instruction in each procedural sentence. Use 20 words or fewer.
- Use 25 words or fewer in each descriptive sentence.
- Put a condition before its instruction. Use direct verbs and active voice.
- Use American English spelling in new user-facing text.
- State the action, state, limit, or result. Remove promotional claims and filler.
- Keep legal permissions, restrictions, and uncertainty exact. Get legal review
  before you change their meaning.

These rules guide editing. A passing code review does not establish full
ASD-STE100 compliance. That claim needs a review against the official rules and
dictionary. Use the official text as the authority for an exact compliance check.
